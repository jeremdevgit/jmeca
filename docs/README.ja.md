# JMeca

[English](../README.md) · [Français](../README.fr.md)

Windows、macOS、Linux 用のデスクトップ車両メンテナンス トラッカー。

インターフェイスは、最初の起動時にシステム言語に従います。アプリ内で変更できます。

## 特長

- クライアント フォルダーで複数の車両を管理し、フリートを検索します。
- 日付と走行距離ごとに部品とカスタムメンテナンスのリマインダーを追跡します。
- サービス記録、請求書、写真、登録書類を暗号化された保管庫に保管します。
- 燃料消費量と経費を記録します。公式オープンデータを使用してフランスのガソリンスタンドを検索します。
- 3,604 の車両バージョンと一般的な 3D 車のシルエットのオフライン カタログからお選びください。

## デモを試してみる

Tauri の前提条件をインストールしてから、`npm ci` および `npm run desktop:dev` を実行します。デモでは架空のデータが使用されています。

個人データの場合は、12 文字以上のパスワードを使用し、暗号化されたバックアップを別のドライブにエクスポートします。

## セキュリティと制限事項

- Vault のコンテンツは保存時に AES-256-GCM で暗号化されます。侵害されたコンピュータは、ロックが解除されている間もボールトにアクセスできます。
- 正確な車両のマニュアルと照合して、整備間隔と互換性のある部品を確認してください。カタログは認定メンテナンス データベースではありません。
- ガソリンスタンド検索はEssence&CoのAPIではなく、フランスの公式オープンデータを利用している。リマインダーはアプリを開いている間のみ表示されます。
- このバージョンは、大規模なマルチユーザー フリートではなく、個人のガレージや地元の小さな作業場に適しています。
