# JMeca

[English](../README.md) · [Français](../README.fr.md)

适用于 Windows、macOS 和 Linux 的桌面车辆维护跟踪器。

首次启动时，界面将遵循您的系统语言。您可以在应用程序中更改它。

## 特点

- 管理客户端文件夹中的多辆车辆并搜索您的车队。
- 按日期和里程跟踪零件和自定义维护提醒。
- 将服务记录、发票、照片和注册文件保存在加密的保管库中。
- 记录油耗和费用。使用官方开放数据搜索法国加油站。
- 从包含 3,604 个车辆版本和通用 3D 汽车轮廓的离线目录中进行选择。

## 尝试演示

安装 Tauri 必备组件，然后运行 `npm ci` 和 `npm run desktop:dev`。该演示使用虚构数据。

对于个人数据，请使用至少 12 个字符的密码并将加密备份导出到另一个驱动器。

## 安全性和限制

- 保管库内容使用 AES-256-GCM 进行静态加密。受感染的计算机可以在解锁时访问保管库。
- 根据您的车辆手册检查保养间隔和兼容零件。该目录不是经过认证的维护数据库。
- 该站搜索使用法国官方开放数据，而不是 Essence&Co API。仅当应用程序打开时才会出现提醒。
- 该版本适用于个人车库或当地小型车间，而不是大型多用户车队。
